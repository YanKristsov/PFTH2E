### 5. Классы — "Недоступно"
Поле `classes` пусто у всех 2009 записей. Причина:
- `parse-spells.ts:172` (AoN) — `classes: []`
- `parse-spells.ts:320` (pf2.ru) — `classes: []`
- Детали pf2.ru API (`text_output`) не содержат `<b>Классы:</b>`
- AoN Search API не предоставляет поле `classes` в `_source`

**Решение:** Отображать текст «Недоступно — источник pf2.ru не предоставляет информацию о классах».
