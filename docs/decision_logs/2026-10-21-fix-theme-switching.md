# Исправление переключения светлой и тёмной темы

## Контекст
Пользователь сообщил, что светлая и тёмная темы не переключаются. Воспроизведено
в браузере с эмуляцией системной тёмной темы: клик «☀️ Светлая» в настройках менял
сохранённую настройку (`localStorage`), но страница оставалась тёмной.

## Причина
`applyTheme()` в `src/stores/index.ts` управлял только классом `dark` на `<html>`:
```ts
root.classList.toggle('dark', theme === 'dark')
```
Класс `light` не выставлялся никогда. При этом в `src/assets/styles/variables.css`
есть блок
```css
@media (prefers-color-scheme: dark) {
  :root:not(.light):not(.light-mode) { /* тёмные переменные */ }
}
```
Селектор `:not(.light)` рассчитан на явный класс светлой темы, которого никто не ставил.
Поэтому на системе с тёмной темой:
- «Светлая» → `<html>` без класса `dark`, но медиазапрос всё равно применял тёмные переменные;
- «Тёмная» и «Системная» давали одинаковый результат.

Итог: на тёмной ОС темы не переключались, на светлой ОС — переключались.

Дополнительно: слушатель `prefers-color-scheme` добавлялся только в момент создания
стора и не снимался; при переходе в режим «Системная» он не переподключался.

## Решение
1. `src/stores/index.ts`:
   - `applyTheme()` теперь выставляет **ровно один** из классов `dark` / `light` на `<html>`
     по фактически применённой теме (`isDarkTheme()`: `dark` → тёмная, `light` → светлая,
     `system` → по `matchMedia`);
   - слушатель `prefers-color-scheme` добавлен один раз при создании стора и реагирует
     на смену системной темы только в режиме «Системная»;
   - `matchMedia` взят под защиту `typeof window !== 'undefined'`.
2. `index.dev.html` — добавлен инлайн-скрипт в `<head>`, который читает `pf2e-settings`
   из `localStorage` и ставит класс `dark`/`light` **до первой отрисовки**:
   без него на тёмной ОС сохранённая светлая тема успевала моргнуть тёмной.
   Логика дублирует `applyTheme()`; при недоступном `localStorage` остаётся тема по умолчанию.
   Vite сохраняет инлайн-скрипт при сборке, `scripts/postbuild.mjs` только переименовывает файл.

## Проверка
Playwright, эмуляция ОС в светлой и тёмной темах:
- все три темы («Светлая», «Тёмная», «Системная») переключают `--color-background` корректно
  в обоих режимах ОС;
- тема сохраняется после перезагрузки, класс на `<html>` уже выставлен на `domcontentloaded`
  (нет «моргания» темы);
- кнопка темы в хедере корректно циклит light → dark → system;
- режим «Системная» реагирует на смену системной темы без перезагрузки;
- иконки затрат действий инвертируются в тёмной теме (`filter: invert(1)`) и не инвертируются
  в светлой;
- `npm run lint`, `npm run typecheck`, `npm run test`, `npm run build` — без ошибок.
