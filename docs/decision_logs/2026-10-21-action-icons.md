# Иконки затрат действий в таблице заклинаний

## Контекст
Столбец «Действия» показывал только текстовую подпись («2 действия», «Реакция»). Требовалось
добавить графические иконки затрат действий, сохранив текстовые подписи, и разобраться с
`PF_action_reaction.png`, у которого был непрозрачный белый фон.

Исходные ассеты (все — чёрные силуэты на прозрачном фоне, кроме реакции):
- `PF_action_1.webp` — 176×176, одна стрелка;
- `PF_action_2.webp` — 277×176, две стрелки;
- `PF_action_3.webp` — 367×177, три стрелки;
- `PF_action_free.webp` — 178×178, свободное действие (контур с белой внутренней частью);
- `PF_action_reaction.png` — 1172×1018, **непрозрачный белый фон**, всего 2 цвета (чёрный/белый).

Значения `castTime` в `public/spells.json` (2009 заклинаний): `Two Actions` (1083), `Single Action` (261),
`Three Actions` (214), `Reaction` (97), `Free Action` (10), диапазоны (`Single Action to Three Actions` — 30),
комбинации (`Two Actions or Three Actions`, `Reaction or Single Action` и др.), длительности (`1 minute`, `8 hours`).

## Альтернативы
1. **Показывать иконку всегда** (в т. ч. для диапазонов) — визуально шумно и вводит в заблуждение:
   у «1–3 действия» нет единственного варианта затрат.
2. **CSS-маска (`mask-image`)** вместо `<img>` — иконка получила бы цвет текста, но потеряла внутреннюю
   белую часть у `PF_action_free.webp` (у маски важна альфа, а у этого файла она непрозрачна и в белой части).
3. **`filter: invert(1)` в тёмной теме** — выбрано: сохраняет внутренние детали иконок, а чёрный силуэт
   становится белым на тёмном фоне.
4. **Удаление белого фона у реакции** через canvas/Playwright — в проекте нет библиотек обработки
   изображений (`sharp`, `pngjs`, `jimp` отсутствуют), а Playwright-версия анализатора ломалась на
   сериализации функции в `page.evaluate` (ошибка `__name is not defined` из-за `keepNames` в tsx).

## Решение
1. **Иконки ставятся только для однозначных значений**: 1, 2, 3 действия, свободное действие, реакция.
   Для диапазонов («1–3 действия»), комбинаций («2 или 3 действия», «Реакция или 1 действие») и
   длительностей остаётся только текст.
2. **Резолвер в `src/constants/translations.ts`**: функция `actionIcon(castTime)` возвращает
   `{ file, src, width, height }` или `null`. `src` собирается из `import.meta.env.BASE_URL`
   (`/PFTH2E/art/<file>`), поэтому ассеты корректно работают и на GitHub Pages, и на dev-сервере.
   Родные размеры ассетов отдаются вместе с иконкой, чтобы браузер резервировал место до загрузки
   (без скачка вёрстки при `loading="lazy"`).
3. **Ассеты лежат в `public/art/`** и копируются в корень `dist`, а значит попадают в корень ветки
   `gh-pages` → итоговый путь `/PFTH2E/art/<file>`.
4. **Белый фон реакции удалён**: изображение бинарное (только чёрный и белый), поэтому «ключевой перенос»
   белого в прозрачность точен. Дополнительно картинка обрезана по содержимому и уменьшена
   до 256×222 box-фильтром (с премноженной альфой) — 1172×1018 (13.7 КБ) → 256×222 (3.0 КБ).
   Кодек PNG написан на чистом Node (`zlib` + CRC32), без новых зависимостей.
5. **Тёмная тема**: `:global(.dark) .action-icon { filter: invert(1) }` — чёрные силуэты становятся
   белыми, белая внутренняя часть `PF_action_free.webp` — чёрной.
6. **Доступность**: `alt` и `title` иконки равны текстовой подписи, подпись остаётся рядом с картинкой.
7. **Офлайн**: в `globPatterns` Workbox добавлен `webp` (иначе `.webp` не попадал в precache),
   `.png` уже был в списке. Все пять иконок проверены в `dist/sw.js`.

- `npm run lint`, `npm run typecheck`, `npm run test` — без ошибок (добавлены тесты на маппинг иконок

  ширина документа = ширина вьюпорта (1440 px и 390 px); в тёмной теме `filter: invert(1)`,
  в светлой — `none`; фильтр «Свободное» → 10 заклинаний с `PF_action_free.webp`,
  фильтр «Реакция» → 49 заклинаний с `PF_action_reaction.png` (256×222)
