# Удаление экспорта/импорта данных

## Контекст
В разделе «Настройки» был блок «Данные» с тремя частями: «Экспорт всех данных»
(скачивание JSON-бэкапа с настройками, избранным и историей), «Импорт данных»
(восстановление из ранее скачанного JSON) и «Очистка данных». На странице «Избранное»
дополнительно были кнопки «📥 Экспортировать JSON» / «📥 Импортировать JSON» — тот же
бэкап-механизм, ограниченный избранным. Пользователь решил, что функция не нужна.

## Альтернативы
1. **Оставить только экспорт** — пользователь не сможет вернуть данные после очистки браузера
   или смены устройства; половина функции остаётся.
2. **Спрятать в отдельный диалог** — усложнение интерфейса без пользы.
3. **Полное удаление** — выбранный вариант: удалены обе части (экспорт и импорт) и весь
   сопутствующий код.

## Решение
Удалено:
- блок «Экспорт всех данных» и «Импорт данных» из `src/views/SettingsView.vue`
  (функции `downloadExport`, `handleImportFile`, `doImport`, состояния `allData`,
  `importFile`, `importError`; из импортов убран `computed`);
- кнопки «📥 Экспортировать JSON» / «📥 Импортировать JSON» и функции `exportFavorites`,
  `importFavorites` из `src/views/FavoritesView.vue`;
- методы `exportSettings`, `importSettings` (стор настроек) и `exportFavorites`,
  `importFavorites` (стор избранного) из `src/stores/index.ts`.

Сохранено:
- блок «Очистка данных» (избранное, история, сброс настроек) — он остаётся полезным;
- кнопка «Экспортировать заклинание» в деталях заклинания — это экспорт текста конкретного
  заклинания, а не бэкап пользовательских данных.

В секции «Данные» настроек заголовок «Очистка данных» сохранён, добавлено пояснение
о необратимости действия.

## Проверка
- `npm run lint`, `npm run typecheck`, `npm run test` — без ошибок
- `npm run build` — успешно
- `npx tsx scripts/check-runtime.ts` — 0 console errors, 0 failed requests
- В браузере: в настройках нет блоков экспорта/импорта, на странице «Избранное» нет кнопок JSON
