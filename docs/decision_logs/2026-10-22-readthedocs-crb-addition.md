# Добавление заклинаний из readthedocs (официальный перевод CRB 2020)

## Контекст
readthedocs (pf2e-ru-translation.readthedocs.io) — официальный перевод Pathfinder 2e Core Rulebook 2020 г. на русский. Кэш всех 724 страниц сохранён локально. Из 704 страниц заклинаний:
- 120 уже присутствуют в базе по AoN ID (заменены Remaster-версиями)
- 230 дублируют Remaster-версии по русскому названию
- 342 имеют уникальные русские названия

После вычета совпадений по английскому названию (spellKey) в базе осталось 123 новых уникальных заклинания.

## Альтернативы
### А) Добавить все 572 readthedocs заклинания как источник вариантов
Все 704 readthedocs страницы добавляются как варианты источника `pf2e-ru-translation`. У 230 дублей по русскому названию показывается источник «Core Rulebook» / «Player Core» в карточке и таблице.
- Плюс: полный официальный перевод CRB в каталоге; пользователь видит оба перевода (Remaster и CRB 2020)
- Минус: требует расширения SpellSourceSchema (уже поддерживает массив вариантов источника), добавления sourceId/sourceTitle в RawSpell

### Б) Добавить только 342 без дублей названий
Только заклинания с уникальными русскими названиями добавляются как новые записи.
- Плюс: без правок интерфейса
- Минус: часть классических заклинаний остаётся недоступна в CRB-переводе

### В) Не добавлять CRB-оригиналы
readthedocs остаётся только источником русского текста для 120 уже присутствующих заклинаний.
- Плюс: никаких изменений
- Минус: 572 заклинания отсутствуют в каталоге

## Решение
Выбран вариант **А** — добавить все readthedocs заклинания как варианты источника `pf2e-ru-translation` с `sourceTitle: 'Core Rulebook'`.

### Обоснование
1. mergeSpells уже поддерживает несколько вариантов источника (массив `source` в SpellSchema)
2. SpellDetailView уже имеет блок «Варианты источника» для отображения всех вариантов
3. spellKey() уже используется для сопоставления заклинаний по английскому названию
4. readthedocs — официальный перевод CRB 2020 г., добавляет 123 уникальных заклинания, которых нет в Remaster
5. Интерфейс не требует изменений — вариант источника отображается в существующем блоке

### Технические изменения
- `scripts/parse-spells.ts`: добавлены `READTHEDOCS_TRAIT_RU_TO_EN`, `READTHEDOCS_ACTION_RU_TO_EN`, `READTHEDOCS_COMPONENT_RU_TO_EN`, `READTHEDOCS_TRADITION_RU_TO_EN`, `READTHEDOCS_SCHOOL_RU_TO_EN` словари; `parseReadthedocsSpell()` (regex-парсинг без JSDOM для предотвращения OOM); `fetchReadthedocsSpells()` (чтение из локального кэша); `readthedocs` добавлен в `SPELL_SOURCES`
- `src/constants/translations.ts`: добавлен перевод для черты `Inhaled → Вдыхаемый`
- `scripts/check-live.ts`: добавлена проверка наличия «Core Rulebook» в источниках
- `scripts/parse-spells.test.ts`: добавлены тесты для `parseReadthedocsSpell()`
