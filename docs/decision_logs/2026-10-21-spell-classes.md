# Сведения о классах заклинаний

## Контекст
Поле `classes` у заклинаний было пустым: источники не давали привязки к классам,
в сайдбаре стояла заглушка «Недоступно — источник pf2.ru не предоставляет информацию о классах»,
колонка «Классы» в таблице была пустой, в деталях выводилось пустое значение.
Пользователь попросил взять сведения о классах с трёх сайтов:
- https://pf2.ru/classes
- https://pf2e-ru-translation.readthedocs.io/ru/latest/classes/index.html
- https://2e.aonprd.com/Classes.aspx

## Что удалось получить из каждого источника

| Источник | Данные | Объём |
|---|---|---|
| **Archives of Nethys** (Elasticsearch) | у каждого заклинания есть массив `trait`; часть трейтов — классы (`Cleric`, `Sorcerer`, `Wizard`…) | 517 заклинаний с классами, **485 из наших 2009 (24%)** |
| **pf2.ru** | 29 классов; на странице каждого — таблица фокусных заклинаний с русскими и английскими названиями; в `h1` — русское и английское имя класса | 29 классов, 412 заклинаний в фокусных списках |
| **pf2e-ru-translation** (readthedocs) | 23 класса с официальными русскими названиями; страница `spells/spell-lists.html` — списки заклинаний по традициям, не по классам | 23 класса (список для сверки) |

Проверка: фокусные списки pf2.ru оказались **строгим подмножеством** данных AoN
(0 дополнительных заклинаний, 1 расхождение), поэтому приоритет отдан трейтам AoN,
а pf2.ru используется как второй источник привязки и как источник русских названий классов.

## Решения (согласованы с пользователем)
1. **Привязка заклинание → классы** — из всех трёх источников: трейт-класс AoN + фокусные
   списки pf2.ru, readthedocs — для сверки списка классов и названий.
2. **Русские названия классов** — словарь из pf2.ru (29 классов).
3. **Интерфейс** — фильтр «Класс» в сайдбаре + колонка «Классы» в таблице (включена по умолчанию)
   + блок «Классы» на странице заклинания.
4. **Заклинания без данных о классе** — помечаются как «Общее заклинание»
   (и в таблице, и в карточке, и в деталях; в фильтре — отдельный пункт).

## Реализация
### Сбор данных (`scripts/parse-spells.ts`)
- `CLASS_NAMES` — список 29 классов (Archives of Nethys, `Classes.aspx`);
  трейт с таким именем — это принадлежность к классу, а не дескриптор.
- `parseAoNRecord()`: трейты-классы переносятся в `classes` и убираются из `traits`.
- `parsePf2ru()`: у pf2.ru класс приходит трейтом с русским названием («Чародей»);
  такие трейты переносятся в `classes` по обратному словарю `CLASS_BY_RU`.
- `fetchClassData()`: обход 29 страниц классов pf2.ru → английские названия фокусных
  заклинаний каждого класса + русские названия классов; отдельно запрашивается
  список классов readthedocs и логируются расхождения названий.
- После слияния источников проверяется, что у каждого класса в данных есть
  русский перевод в `src/constants/translations.ts` (иначе парсер пишет ошибку).

### Интерфейс
- `src/constants/translations.ts`: `CLASS_LABELS` (29 классов), `classLabel()`,
  псевдокласс `GENERIC_CLASS` и подпись `GENERIC_CLASS_LABEL` («Общее заклинание»).
- `src/composables/useSpells.ts`: фильтр по классу учитывает псевдокласс
  (выбираются заклинания без классов); список классов сортируется по русскому названию.
- `src/components/AppSidebar.vue`: секция «Класс» — чекбоксы классов + пункт «Общее заклинание».
- `src/components/SpellTable.vue`, `SpellCard.vue`, `src/views/SpellDetailView.vue`:
  названия классов через `classLabel()`, для заклинаний без классов — «Общее заклинание».
- `src/types/spell.ts`, `src/stores/index.ts`: колонка «classes» включена по умолчанию.
- Исправлен `FILTER_LABELS.classes` → `class` (в чипе активных фильтров было «class:»).

### Смежная правка
Дескрипторы pf2.ru приходят русскими названиями, поэтому в данных одни и те же
дескрипторы дублировались (английский + русский): в фильтре «Черты» было 188 пунктов
вместо 109, в карточке — «Редкий Редкий». Дескрипторы нормализованы к английским
названиям (`TRAIT_BY_RU`); неоднозначные подписи («Призыв» = Conjuration/Summon,
«Сон» = Dream/Sleep, «Несмертельное» = Incapacitation/Nonlethal,
«Превращение» = Morph/Transmutation) не переводятся — таких 10 из 109.

## Покрытие
485 заклинаний из 2009 (24%) принадлежат одному из 15 классов:
Cleric 135, Sorcerer 53, Wizard 48, Witch 39, Oracle 37, Necromancer 27, Bard 22,
Ranger 22, Druid 21, Psychic 18, Monk 15, Magus 14, Animist 14, Champion 13, Summoner 7.
Остальные 1524 заклинания (76%) — «Общее заклинание»: это заклинания из дополнительных
книг, которые не входят в списки фокусных заклинаний ни одного класса.

## Расхождения русских названий классов
У 4 из 23 классов перевод readthedocs (CRB) отличается от pf2.ru — приоритет у pf2.ru
(по решению пользователя):
| Класс | pf2.ru | readthedocs |
|---|---|---|
| Champion | Поборник | Чемпион |
| Investigator | Следователь | Сыщик |
| Magus | Колдун | Магус |
| Ranger | Следопыт | Рейнджер |

## Проверка
- `npm run parse:spells` — 29 классов pf2.ru, 412 заклинаний в фокусных списках,
  23 класса readthedocs, 4 расхождения названий (логируются), 15 классов в данных
- `npm run lint`, `npm run typecheck`, `npm run test` (26 тестов), `npm run build` — без ошибок
- `npx tsx scripts/check-runtime.ts` — 0 console errors, 0 failed requests
- Браузер: колонка «Классы» в таблице, 16 пунктов в фильтре «Класс» (15 классов +
  «Общее заклинание»), фильтр по «Волшебник» → 48 строк, по «Общее заклинание» →
  только заклинания без классов; на 390 px горизонтального переполнения нет
- `scripts/check-live.ts` — добавлены проверки фильтра «Класс», колонки «Классы»
  и отсутствия английских названий классов в UI
