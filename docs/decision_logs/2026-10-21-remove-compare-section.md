# Удаление раздела «Сравнение»

## Контекст
Раздел «Сравнение» (до 3 заклинаний в таблице) был реализован как отдельный маршрут `/compare`
с собственным view, Pinia-стором и набором точек входа: чекбоксы в таблице заклинаний,
кнопка ⚖️ в карточке, кнопка в деталях заклинания, панель «Добавить к сравнению (N/3)»
на главной странице и в истории просмотров. Пользователь запросил полностью убрать
раздел и связанную с ним механику.

## Альтернативы
1. **Скрыть только пункт навигации** — раздел остался бы доступен по прямой ссылке `/compare`,
   а вся обвязка (стор, чекбоксы, кнопки) продолжала бы занимать место в коде и в UI.
2. **Оставить механику выбора, но без экрана сравнения** — пользователь выбирал бы заклинания
   без возможности увидеть результат.
3. **Полное удаление** — выбранный вариант: раздел и вся связанная механика убраны из кода,
   из UI и из навигации.

## Решение
Удалены полностью:
- `src/views/CompareView.vue` (файл);
- маршрут `/compare` в `src/router/index.ts` (теперь работает catch-all → редирект на `/`);
- `useComparisonStore` из `src/stores/index.ts` (стор `comparison` с `items/add/remove/toggle/clear/isInComparison`);
- пункты навигации «Сравнение» в `src/components/AppHeader.vue` (мобильное меню)
  и `src/components/AppSidebar.vue` (список «Основная навигация»);
- кнопка ⚖️ «Добавить к сравнению» в `src/components/SpellCard.vue`;
- кнопка «Добавить к сравнению» в деталях заклинания (`src/views/SpellDetailView.vue`);
- колонка «Выбрать» с чекбоксами в `src/components/SpellTable.vue` вместе с пропом `selected`,
  эмитом `select`, классом `.selected` и `:aria-selected` на строках;
- панель «Добавить к сравнению (N/3)» + «Очистить выбор» на главной (`HomeView.vue`)
  и в истории (`HistoryView.vue`) вместе с состоянием `selectedSpells`;
- кнопка ⚖️ в таблице избранного (`src/views/FavoritesView.vue`).

Изменённые контракты компонентов:
- `SpellTable`: проп `selected` и эмит `select` удалены; клик по строке, Enter и Space
  всегда открывают детали заклинания (ранее Ctrl/Cmd+клик и Shift+Enter выбирали заклинание
  для сравнения);
- `SpellCard`: проп `is-in-comparison` и эмит `compare` удалены.

## Проверка
- `npm run lint`, `npm run typecheck`, `npm run test` — без ошибок
- `npm run build` — успешно, чанк `CompareView` больше не генерируется
- `npx tsx scripts/check-runtime.ts` — 0 console errors, 0 failed requests
- В браузере: в навигации нет пункта «Сравнение», в таблице нет колонки «Выбрать»,
  переход на `/compare` перенаправляет на главную
